# Журнал изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [Semantic Versioning](https://semver.org/lang/ru/).

## [0.1.1] — 2026-10-14 — этап A, стабилизация

### Добавлено
- Фоновый импорт: поиск файлов, чтение метаданных, копирование и подготовка миниатюр в отдельном потоке; прогресс по файлам, кнопка «Отменить импорт», снимки появляются в списке по ходу импорта.
- Отчёт о пропущенных файлах с причинами (повреждён/не читается, уже в проекте, формат не поддерживается, ошибка копирования).
- Проверка свободного места перед импортом.
- Дисковый кэш миниатюр `cache/thumbs` и асинхронная загрузка миниатюр в списке и ленте.
- Блокировка проекта `geomap.lock`: второй экземпляр программы не может открыть тот же проект; блокировка аварийно завершившегося процесса заменяется.
- Подтверждение закрытия окна во время импорта; уже скопированные снимки сохраняются.
- Параметр запуска `--settings-dir`; версия в интерфейсе берётся из сборки.
- `CMakePresets.json`, CI для Windows и Linux (`.github/workflows/ci.yml`), параметры `-OutDir` и `-Zip` скрипта сборки, генератор тестового набора `scripts/generate-test-flight.ps1`.
- Тесты фонового импорта, отмены, отзывчивости цикла событий, кэша миниатюр, блокировки; всего 3 тестовых исполняемых файла.
- Документация: `docs/AUDIT.md`, `docs/ROADMAP.md`, `docs/BUILD.md`, `docs/TESTING.md`, `docs/PROJECT_FORMAT.md`, `docs/DEPENDENCIES.md`.

### Исправлено
- Приложение не открывалось: `Main.qml` не загружался из-за свойств отступов у `RowLayout`.
- Импорт через «+ Файлы» отбрасывал все файлы (`QVariantList` получал дважды обёрнутые URL).
- EXIF и GPS из JPEG не читались (лишний цикл в `ExifReader`).
- Импорт папки повторно добавлял копии из папки проекта.
- Не удалялись копии снимков, импортированных с носителей «только для чтения».
- Кнопка «Создать» активировалась без выбранной папки.
- Окно не помещалось на экран 1920×1080 при 125 %; колонка инспектора обрезалась.
- Светлые заголовки и панели кнопок в диалогах тёмной темы.
- Пустые миниатюры сразу после открытия проекта.
- Зависания интерфейса до нескольких секунд при импорте и в проектах на сотни снимков: скрытый GPS-обзор перерисовывался в GUI-потоке за O(n²).
- Тесты не запускались через `ctest`; в поставке не было рантайма MSVC.

### Изменено
- Логика проектов и импорта вынесена в статическую библиотеку `GeoMapCore`, общую для приложения и тестов.

## [0.1.0]

Исходная версия: проекты, импорт JPEG/PNG/TIFF, EXIF/GPS, просмотр, схема GPS-точек.
