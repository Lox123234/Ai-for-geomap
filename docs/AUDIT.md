# Аудит GeoMap AI 0.1.0

**Дата:** 2026-10-13 – 2026-10-14
**База:** коммит `c3f8815` (исходники из `GeoMap-AI-0.1.0-source.zip`)
**Окружение проверки:** Windows 11 x64 (26200), Qt 6.8.3 `msvc2022_64`, VS 2022 Build Tools 17.14 (MSVC 14.44), CMake 4.4.3, экран 1920×1080 при 125 %.

## Методика

1. Чтение всех исходников (`app/`, `qml/`, `tests/`, `scripts/`, `CMakeLists.txt`, документация).
2. Сборка Release x64 существующим скриптом, затем сборка с нуля в отдельном каталоге.
3. Запуск существующих тестов, затем тестов, добавленных для проверки заявлений README.
4. Запуск собранного приложения и прогон пользовательских сценариев через Windows UI Automation со снимками окна.
5. Каждая найденная ошибка сначала воспроизводилась (падающим тестом или запуском), затем исправлялась.

Статусы: **работает** — проверено сборкой/тестом/запуском; **не работало → исправлено** — ошибка воспроизведена и исправлена в коммите `3646052`; **не проверено** — проверка не выполнялась.

## Риски (по приоритету)

1. **Зависание UI при импорте больших наборов.** Сотни 20-Мп снимков копируются и разбираются в GUI-потоке. → Этап A.
2. **Нагрузка миниатюр.** Каждая миниатюра декодирует полный JPEG; при 1000 снимках прокрутка тяжёлая. → Этап A.
3. **Два процесса пишут один `geomap.json`.** Второе окно перезапишет изменения первого. → Этап A.
4. **Изменение формата проекта без миграций** сломает открытие старых проектов. → Механизм миграций до первого изменения схемы.
5. **Лицензии при распространении.** В `dist` нет текстов лицензий Qt и сторонних компонентов (LGPL требует их прилагать). Без этого папку нельзя публиковать. → `docs/DEPENDENCIES.md` (этап A), комплект лицензий (этап F, до любой публикации).
6. **Длинные пути Windows (> 260 символов)** не проверены.
7. **Лишние модули в `dist`** (Network, TLS, все стили Controls) увеличивают размер до ~70 МБ.
8. **Недавние проекты** хранят удалённые и перенесённые пути.
9. **Linux не собирался.**

## Блокеры окружения

- Linux-сборка в WSL требует установки пакетов через `sudo` — выполняет владелец.
- GitHub Actions нельзя запустить без удалённого репозитория и `git push` (требуется разрешение владельца).
- Этап B: Docker Desktop установлен, образ ODM не загружен (несколько ГБ — нужна загрузка с подтверждением).
