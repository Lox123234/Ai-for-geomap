# Тестирование GeoMap AI

## Автоматические тесты

```powershell
ctest --test-dir build -C Release --output-on-failure      # Windows, после сборки
ctest --preset windows-release                              # или через пресет
```

```bash
ctest --preset linux-release                                # Linux (QT_QPA_PLATFORM=offscreen)
```

Тесты работают только во временных папках и хранят настройки в отдельном INI, не затрагивая профиль пользователя.

| Исполняемый файл | Что проверяет |
| --- | --- |
| `GeoMapAITests` (`tests/test_exif.cpp`) | EXIF GPS, камера и дата из JPEG; короткие строки EXIF внутри поля значения; размеры PNG/TIFF; кириллические пути; отсутствующие, пустые, мусорные и обрезанные файлы; повреждённый EXIF (смещения за границей, циклы IFD, огромные счётчики, нулевые знаменатели, недопустимые координаты) |
| `GeoMapAIProjectTests` (`tests/test_project.cpp`) | Создание/сохранение/закрытие/повторное открытие; пустой проект; импорт JPEG/PNG/TIFF с кириллицей; дубликаты; относительные пути и перенос проекта; удаление копий без удаления оригиналов (в т. ч. read-only); повреждённые изображения и манифесты; небезопасные пути в `geomap.json`; импорт папки без копий самого проекта; вызов `importFiles` из JavaScript с `list<url>`; **отзывчивость цикла событий при импорте 120 снимков**; отмена импорта; закрытие во время импорта; блокировка проекта вторым экземпляром и замена «мёртвой» блокировки; порядок сигнала папки и сброса модели |
| `GeoMapAIImportTests` (`tests/test_import.cpp`) | `ImportJob`: подсчёт по причинам, лимит файлов при сканировании, исключение папки проекта, отмена между файлами; `ThumbnailCache`: размер и пропорции, повторное использование, пересоздание повреждённого и устаревшего кэша, EXIF-ориентация, небезопасные пути, отсутствующие и битые снимки |

Тест отзывчивости измеряет максимальный интервал между срабатываниями 10-мс таймера GUI-потока во время импорта и требует, чтобы он был меньше 250 мс.

## Тестовые данные

Синтетический «полёт» (сетка GPS, EXIF камеры и времени, PNG, TIFF и битый JPEG) создаётся скриптом; реальные и персональные снимки в репозиторий не добавляются.

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\generate-test-flight.ps1 -OutDir "$env:TEMP\GeoMapFlight130"
powershell -ExecutionPolicy Bypass -File .\scripts\generate-test-flight.ps1 -OutDir "$env:TEMP\GeoMapFlight1040" -Rows 26 -Cols 40
```

## Ручной чек-лист (UI smoke)

Запускать из переносимой папки; для изоляции настроек — `GeoMapAI.exe --settings-dir <временная папка>`.

1. Запуск: окно открывается, тёмная тема, строка состояния видна (на 1920×1080 при 125 % окно развёрнуто).
2. «+ Создать проект» → «Обзор» → папка с кириллицей и пробелами → «Создать». Кнопка «Создать» неактивна, пока папка не выбрана, в т. ч. после отмены «Обзора».
3. «+ Папка» → набор из 130 снимков: прогресс «Импорт N из M», полоса, имя текущего файла; снимки появляются в списке во время импорта; окно перемещается и реагирует.
4. Итоговый статус с числом пропущенных и причинами; «Пропущенные файлы: N» открывает список.
5. Выбор снимков в списке и ленте; инспектор: размер, объём, камера, дата, GPS; снимок без GPS — «Не обнаружены».
6. «GPS-обзор»: точки на своих местах, выбранная подсвечена.
7. Повторный импорт той же папки — все файлы «уже в проекте».
8. Новый проект, импорт и «Отменить импорт» в середине: статус «Импорт отменён. Импортировано: X из M», в `photos/` ровно X файлов.
9. Закрыть окно во время импорта → подтверждение → «Да»: программа закрывается, скопированные снимки записаны в манифест.
10. Перезапуск, открытие проекта из «Недавних»: все снимки и миниатюры на месте.
11. Горячие клавиши: `Ctrl+S`, `Ctrl+I`, `Ctrl+O`, `Ctrl+W`, `Ctrl+N`.
12. «Открыть папку проекта» открывает Проводник.
13. Второй экземпляр программы, тот же проект → «Проект уже открыт в другом окне».
14. Удаление снимка: подтверждение, копия и миниатюра удалены, оригинал на месте.
15. Ещё не автоматизировано и не выполнено: отказ доступа к папке проекта, нехватка места на диске (проверка места реализована, но не воспроизводилась), пути длиннее 260 символов.
