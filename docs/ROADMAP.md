# GeoMap AI — дорожная карта

Источник требований: `GeoMap-AI_MASTER_TZ.md`. Этапы выполняются по порядку A → G. Этап закрывается только после сборки, тестов и проверки результата; пункт отмечается выполненным только при наличии доказательства (тест, запуск, отчёт).

Обозначения: `[x]` выполнено и проверено, `[ ]` не выполнено, `[~]` выполнено частично (см. примечание).
