# GeoMap AI — дорожная карта

Источники требований: `GeoMap-AI_MASTER_TZ.md` и дополнение «GeoMap AI — Professional Edition» (функциональное соответствие Agisoft Metashape Professional; учёт по функциям — `docs/METASHAPE_FEATURE_PARITY.md`, по командам интерфейса — `docs/UI_COMMANDS.md`). Этапы выполняются по порядку A → G; требования дополнения распределены по этапам ниже. Этап закрывается только после сборки, тестов и проверки результата; пункт отмечается выполненным только при наличии доказательства (тест, запуск, отчёт).

Обозначения: `[x]` выполнено и проверено, `[ ]` не выполнено, `[~]` выполнено частично (см. примечание).
