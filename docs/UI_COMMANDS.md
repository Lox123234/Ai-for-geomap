# Команды интерфейса GeoMap AI

Документ создан скриптом `scripts/generate-ui-commands.ps1` из `src/ui/commands/commands.json` — единого списка команд, из которого строятся меню, панель инструментов и горячие клавиши. Не редактируйте его вручную.

Всего команд: 152: готовых — 152, запланированных — 0, не поддерживаемых движком — 0.

Правила:

- Пункт меню, кнопка панели и горячая клавиша одной команды вызывают одну функцию `runCommand(id)` (`qml/Main.qml`), доступность — `commandEnabled(id)`.
- Запланированная команда видна, но отключена; в меню показан этап, в подсказке — причина. Команда «не поддерживается движком» — шаг, который OpenDroneMap не выполняет отдельно.
- Горячие клавиши можно изменить: «Правка → Настройки интерфейса» или «Справка → Горячие клавиши». Конфликты отклоняются.
- Тесты: `GeoMapAIWorkspaceTests` проверяет целостность списка, иконки, клавиши и этот документ; `GeoMapAIUiTests` загружает настоящее окно и проверяет, что у каждой готовой команды есть обработчик, а запланированные отключены.
